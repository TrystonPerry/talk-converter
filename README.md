# Talk Converter

A powerful CLI tool that helps you split long YouTube videos into individual talk segments, complete with transcripts and AI-generated descriptions.

![Talk Converter Preview](https://github.com/TrystonPerry/talk-converter/blob/main/youtube-converter.png)

## Setup

1. **Prerequisites**

   - Bun (v1.3 or higher)
   - ffmpeg (required for video processing)
   - yt-dlp (required for downloading source videos and captions)
   - Claude Code CLI, logged in (for AI-powered summaries)

2. **Installation**

   ```bash
   # Clone the repository
   git clone [repository-url]
   cd talk-converter

   # Install system tools (Arch)
   sudo pacman -S ffmpeg yt-dlp

   # Install dependencies
   bun install
   ```

   Summaries are generated by shelling out to `claude --print`, so it uses
   whatever Claude Code is already authenticated with — no API key to manage.

## How to Use

1. **Basic Usage**

   The `__talks` and `__youtube` folders are created automatically on first run.
   The source video is downloaded via yt-dlp (720p minimum) into
   `__youtube/{YouTube Video ID}.mp4`, and the video's English captions into
   `__youtube/{YouTube Video ID}.en.vtt`. Both are reused on subsequent runs, so
   the full video is only fetched once no matter how many talks you slice from it.

   You don't time the talks yourself — the captions are read once and Claude
   picks out where each talk starts and ends, so the whole event is one command:

   ```bash
   npm start -- "https://youtube.com/watch?v=example"
   ```

2. **Check the boundaries first**

   Detection is a judgement call on messy auto-captions, so `--list` prints what
   it found and stops before slicing anything:

   ```bash
   npm start -- "https://youtube.com/watch?v=example" --list
   ```

   ```
   DONE  Identified 2 talks
           1. Freedom with AI: Cammy and Sonia · 0:10:15–0:49:30 (39m 15s)
           2. Designing with Claude Code: Tristan Perry · 0:52:30–1:07:45 (15m 15s)
   ```

3. **Options**

   | Flag | Effect |
   | --- | --- |
   | `--list` | Detect talks and print them, without slicing |
   | `--verbose` | Show every command, its exit code, timing and full output |
   | `--range start,end` | Skip detection and cut one segment (`H:MM:SS` or seconds) |
   | `--title '...'` | Name for that segment — required with `--range` |

   Use `--range`/`--title` when detection gets a talk wrong:

   ```bash
   npm start -- "https://youtube.com/watch?v=example" \
     --range "52:30,1:07:45" --title "Designing with Claude Code"
   ```

4. **Output**
   Per talk, named `{Speaker}_{Title}`:

   - A video file of the extracted segment (`__talks/[name].mp4`)
   - An audio transcript (`__talks/[name].txt`)
   - A markdown file with AI-generated description and article (`__talks/[name].md`)

5. **Processing Steps**
   - Downloads the full YouTube video
   - Downloads the video's English captions
   - Reads the whole timestamped transcript to identify each talk's boundaries
   - Then, per talk: extracts the segment, slices the captions down to it, and
     writes an AI-generated summary and article

## Notes

- The tool caches downloaded videos, captions, and generated transcripts to avoid reprocessing
- Transcripts come from YouTube's own captions, so a video with captions disabled won't work
- Detected boundaries are quantised to 15 seconds, and being a model's judgement
  they shift slightly between runs — `--list` before a long video is worth it
- `-c copy` makes the video cut snap to the nearest keyframe, so segment boundaries
  can be off by a few seconds
- One talk failing doesn't abort the batch; the rest still run and the failures
  are reported at the end (with a non-zero exit code)
- Video segments are saved in the `__talks` directory
- Original downloaded videos and captions are stored in the `__youtube` directory
